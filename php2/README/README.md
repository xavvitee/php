# Практична робота №2: Блог/CMS для статей

## Про проєкт

Було розроблено простий вебзастосунок для створення статей у блозі. Користувач може ввести заголовок, текст статті та теги. Дані обробляються за допомогою PHP, а чернетка автоматично зберігається у `localStorage`.

## Основний функціонал

* **Створення статті** : користувач вводить заголовок, текст статті та теги через HTML-форму.
* **Валідація даних** : введені дані перевіряються на стороні браузера за допомогою HTML5 і JavaScript, а також повторно на сервері за допомогою PHP.
* **Обробка помилок** : якщо дані введені неправильно, користувач отримує повідомлення про помилку, а вже введені значення зберігаються у формі.
* **Збереження чернетки** : введені дані автоматично зберігаються у `localStorage`, тому їх можна відновити після перезавантаження сторінки.
* **Надсилання статті** : після успішної перевірки на сторінці відображаються прийняті дані та повідомлення про успішне надсилання.
* **Безпечний вивід** : введені користувачем дані виводяться через `htmlspecialchars()`, що забезпечує базовий захист від XSS-атак.

## Структура проєкту

`form.php` містить PHP-обробник, HTML-форму та JavaScript-код.
`style.css` відповідає за оформлення вебсторінки.

## Як запустити локально

1. Відкрити папку проєкту у VS Code.
2. У терміналі перейти до папки `php2`.
3. Запустити локальний сервер PHP:

```text
php -S localhost:8000
```

4. Відкрити у браузері:

```text
http://localhost:8000/form.php
```

Після цього відкриється форма створення нової статті.
