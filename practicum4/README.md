Практична робота №4: Блог/CMS для статей
Про проєкт
Розроблено вебзастосунок для керування статтями блогу на PHP з базою даних MySQL через розширення PDO. Статті зберігаються в таблиці articles, а застосунок виконує повний набір CRUD-операцій: виведення, додавання, редагування та видалення.
Основний функціонал
• Підключення до БД: у db.php створюється об'єкт PDO з режимами ERRMODE_EXCEPTION і FETCH_ASSOC.
• Таблиця articles: стовпці id (первинний ключ з автоінкрементом), title, content, author, published_at.
• Функції роботи з даними: findByAuthor(), listRecent(), addArticle(), updateArticle() та deleteArticle(). Усі запити підготовлені; у listRecent() значення LIMIT передається через bindValue() з типом PDO::PARAM_INT.
• Виведення даних: index.php показує статті в HTML-таблиці через fetchAll(), має пошук за автором та перегляд п'яти останніх статей.
• Додавання та редагування: форми в add.php і edit.php перевіряють порожні поля, після збереження перенаправляють на index.php через header('Location: index.php').
• Видалення: delete.php приймає лише POST-запити, а перед відправленням форми confirm() просить підтвердження.
• Безпека: підготовлені запити захищають від SQL-ін'єкцій, а htmlspecialchars() у функції e() захищає вивід від XSS. Тест із символом ' та рядком ' OR '1'='1 не порушив структуру запиту: значення оброблено як звичайний текст.
Структура проєкту
• schema.sql створює базу даних practicum4 і таблицю articles.
• db.php містить підключення до бази даних.
• articles.php містить функції роботи з таблицею та допоміжну e().
• index.php виводить список статей, пошук і останні статті.
• add.php містить форму та обробку додавання статті.
• edit.php містить форму та обробку редагування статті.
• delete.php видаляє статтю за id.
Як запустити локально
1. Запустити Apache і MySQL у XAMPP Control Panel.
2. Відкрити http://localhost/phpmyadmin, перейти на вкладку Import і імпортувати schema.sql.
3. Скопіювати файли проєкту до папки C:\xampp\htdocs\practicum4.
4. Відкрити в браузері http://localhost/practicum4/index.php.
Після цього відкриється сторінка зі списком статей блогу.
