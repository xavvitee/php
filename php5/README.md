# Практична робота №5: Блог/CMS для статей

### Про проєкт

Розроблено вебзастосунок «Блог» на PHP, JavaScript і MySQL, у якому фронтенд обмінюється даними з бекендом через AJAX (`fetch`) у форматі JSON. Статті з таблиці `articles` завантажуються, шукаються та додаються без перезавантаження сторінки.

### Основний функціонал

* **Підключення до БД:** у `db.php` створюється об'єкт PDO для бази `practicum4` з режимами `ERRMODE_EXCEPTION` і `FETCH_ASSOC`.
* **JSON-ендпоінт списку:** `api_list.php` повертає масив статей зі стовпцями `id`, `title`, `content`, `author`, `published_at`, від найновіших до найстаріших. Параметр `q` фільтрує статті за заголовком через підготовлений запит із `LIKE`. Відповідь формується через `json_encode` із заголовком `Content-Type: application/json`, а при помилці бази повертається код 500.
* **Завантаження списку:** `index.html` містить лише порожній контейнер `#results`, поле пошуку `#search` і форму додавання. Під час відкриття сторінки `script.js` викликає `fetch('api_list.php?q=')` і виводить статті в контейнер.
* **Живий пошук:** на подію `input` поля пошуку виконується `fetch('api_list.php?q=' + encodeURIComponent(...))`, після чого контейнер перемальовується без перезавантаження сторінки.
* **Ендпоінт додавання:** `api_add.php` приймає лише POST-запити (інакше код 405), читає дані з JSON-тіла через `php://input` або з `$_POST`, перевіряє порожні поля (код 400), виконує підготовлений `INSERT` із `NOW()` для `published_at` і повертає доданий запис у форматі JSON із кодом 201.
* **Додавання без перезавантаження:** форма обробляється через `event.preventDefault()`, дані надсилаються методом POST у форматі JSON. Нова стаття вставляється на початок списку через `insertAdjacentHTML('afterbegin', ...)`, а форма очищується.
* **Обробка помилок:** у кожному запиті перевіряється `response.ok`, помилки мережі та сервера перехоплюються через `try...catch` і виводяться повідомленням у контейнері `#results`, а не лише в консолі.
* **Безпека:** підготовлені запити захищають від SQL-ін'єкцій, а функція `escapeHtml()` екранує дані перед вставкою в `innerHTML` і захищає від XSS.
* **Перевірка в DevTools:** у вкладці Network (фільтр Fetch/XHR) запит `api_list.php?q=` має тип `fetch`, статус 200 та ініціатора `script.js`; запит `api_add.php` також виконується через `fetch`. У вкладці Elements новий елемент `<article>` з'являється без повторного завантаження документа.

### Структура проєкту

* `schema.sql` створює таблицю `articles` у базі даних `practicum4`.
* `db.php` містить підключення до бази даних.
* `api_list.php` повертає список статей у форматі JSON із фільтром за заголовком.
* `api_add.php` додає статтю через POST-запит і повертає її з кодом 201.
* `index.html` містить контейнер результатів, поле пошуку та форму додавання статті.
* `script.js` виконує `fetch`-запити, оновлює DOM, реалізує живий пошук і обробляє помилки.

### Як запустити локально

1. Запустити Apache і MySQL у XAMPP Control Panel.

2. Відкрити phpMyAdmin, обрати базу `practicum4`, перейти на вкладку **Import** та імпортувати `schema.sql`:

   ```text
   http://localhost/phpmyadmin
   ```

3. Скопіювати файли проєкту до папки:

   ```text
   C:\xampp\htdocs\blog
   ```

4. Відкрити у браузері:

   ```text
   http://localhost/blog/index.html
   ```

Після цього відкриється сторінка зі списком статей блогу, пошуком і формою додавання нової статті.
