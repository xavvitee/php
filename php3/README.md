# Практична робота №3: Блог/CMS для статей

### Про проєкт

Було розроблено невеликий вебзастосунок для відображення статей блогу з використанням об'єктно-орієнтованого програмування в PHP. Статті описуються класами, зберігаються в класі-менеджері та виводяться на сторінці у вигляді таблиці.

### Основний функціонал

* **Базовий клас `Article`:** описує звичайну статтю (заголовок, текст, автор, дата публікації), має конструктор, геттери та метод `getInfo()`. Властивості `title` і `content` оголошені як `private`, `author` і `publishedAt` як `protected`.
* **Похідний клас `FeaturedArticle`:** успадковує `Article`, додає банер і пріоритет. Конструктор викликає `parent::__construct()`, а метод `getInfo()` перевизначено через `parent::getInfo()` з доповненням.
* **Клас-менеджер `Blog`:** зберігає масив статей і має методи `addArticle()` (додавання), `findByAuthor()` (пошук за автором) та `listRecent()` (найновіші статті).
* **Бібліотека функцій:** у файлі `lib/functions.php` розміщено `makeSlug()` (створення slug із заголовка), `truncateText()` (скорочення тексту), а також допоміжні `formatDate()` та `e()`.
* **Виведення даних:** `index.php` створює кілька об'єктів обох класів, додає їх у блог і виводить у таблицю. Рекомендовані статті виділяються та показують розширену інформацію порівняно зі звичайними.
* **Безпечний вивід:** усі дані виводяться через `htmlspecialchars()`.

### Структура проєкту

* `classes/Article.php` містить базовий клас статті.
* `classes/FeaturedArticle.php` містить похідний клас рекомендованої статті.
* `classes/Blog.php` містить клас-менеджер колекції статей.
* `lib/functions.php` містить допоміжні функції.
* `index.php` підключає файли через `require_once`, створює об'єкти та виводить результат.
* `style.css` відповідає за оформлення вебсторінки.

### Як запустити локально

1. Відкрити папку проєкту у VS Code.

2. У терміналі перейти до папки `php3`.

3. Запустити локальний сервер PHP:

   ```text
   php -S localhost:8000
   ```

4. Відкрити у браузері:

   ```text
   http://localhost:8000/index.php
   ```

Після цього відкриється сторінка зі списком статей блогу.
